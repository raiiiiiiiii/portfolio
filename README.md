# anaya

Ultra premium personal portfolio website for Anya: Web3 Digital Artist, Content Creator, and Builder.

## Overview

A handcrafted, cinematic, pink and white world portfolio experience built for Anya. Designed with top creative studio standards, smooth micro-interactions, responsive physics, and zero external framework dependencies.

- Live Testnet Project: ArcSwap on Arc Network
- Brand Ambassadorships: Unitas Labs and moove.xyz
- Visuals: Ethereal pink and white aesthetic, custom video hero background, interactive custom cursor, and particle physics.

## Core Features

- Hero Video Engine: Seamless full-viewport background video with soft pink-to-white gradient overlay.
- Dual Layer Cursor System: Instant dot tracker with lerped outer ring and tactile hover expansion.
- Floating Particle System: Ambient floating stars and orbs with scroll parallax and mobile battery optimization.
- Typewriter Role Engine: Smooth cycling through Anya's creative roles.
- Dedicated Project Showcases: Bespoke cards for ArcSwap, Unitas Labs, and moove.xyz with metrics and post placeholders.
- Vercel Ready: Pre-configured caching headers and clean routing for instantaneous deployments.

## Tech Stack

- Structure: HTML5 Semantic Markup
- Styling: Vanilla CSS with custom property tokens and fluid responsive typography
- Motion: Pure JavaScript and CSS cubic-bezier transition curves
- Deployment: Vercel Static Hosting

## Local Development

Run the lightweight preview server:

```bash
npm start
```

Open `http://localhost:5173` in your browser.

## Deployment to Vercel

Push to GitHub and connect the repository directly in your Vercel dashboard. The included `vercel.json` and `package.json` configurations provide automatic zero-config static hosting with asset caching.
